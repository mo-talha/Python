# Tree
A tree is the data structure that represents a heirarchical relationship b/w data elements called nodes.

# Binary Tree
It is defined as a tree data structure where each node has atmost 2 children.

# Terms in a Binary Tree
1. Node
All the items in a tree.  
2. Root
The topmost item or node in a tree.  
3. Parent
The top node which has child nodes.  
4. Child
The nodes which are connected to a single top node.
5. Edges
The lines connecting the child nodes to the parent node are called edges.    
6. Leaf
The nodes which do not have any child nodes.  
7. Ancestor
All the parent nodes, which lead to the root node from a child node in a straigt line.
8. Descendent 
All the nodes in the downward which are connected to a node, are called Descendent.  
9. Level
10. Sibling
Two Nodes have the same parent node are called siblings.
11. Height
The no of Edges b/w the top node to the bottom node will give us height.  
12. Degree
No of child nodes, for a node.
